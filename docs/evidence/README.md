# Indeks Bukti UTS

Screenshot ditambahkan ketika hasil terkait sudah tersedia.
Jangan menampilkan token, password, APP_KEY, isi .env aktual,
atau nilai GitHub Secrets.

Nama file berikut merupakan penamaan bukti yang direncanakan.
Status di tabel menunjukkan ketersediaannya di repository.

| Bukti | Terkait | Yang harus terlihat | Status di repo |
| --- | --- | --- | --- |

Daftar lengkap kebutuhan bukti mengikuti checklist rubrik di Notion.
Tambahkan baris untuk Actions, branch protection, API/Postman,
frontend, Docker Compose, persistensi, GHCR, dan bonus jika digunakan.

Setiap bukti baru dicatat dengan nomor soal, nama file,
hasil pemeriksaan, dan tautan sumber seperti PR atau Actions.
